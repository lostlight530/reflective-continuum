FOUNDATIONAL TERMS / PLAIN-LANGUAGE REFERENCE基础术语

Canonical Digest / 规范化摘要

SHA-256 identity of canonical JSON bytes, not semantic correctness规范化 JSON 字节的 SHA-256 身份，不是语义正确性证明

KL Divergence / KL 散度

Difference between two declared distributions P and Q, not a graph-health verdict比较两个声明的概率分布 P、Q；不自动等于图谱健康度

Versioned Graph / 版本图

Nodes and edges tied to declared versions for scoped queries带版本号的节点和边，可按指定版本重建和查询

PageRank Entropy / 分布熵

Shannon entropy over normalized PageRank scores; not KL divergence对图谱 PageRank 权重归一化后计算 Shannon 熵，不是 KL

Savepoint / 事务保存点

Only scopes graph changes inside a SQLite transaction, not external effects只约束同一 SQLite 事务里的图变更，不能回滚外部副作用

Store Identity / 存储身份

Named DB path, version and run context are needed for continuity claims需要具体数据库路径、版本、运行上下文，才能讨论跨运行连续性

Important distinction:重要边界： Axiom's KL divergence compares declared P and Q; Reflective's Shannon entropy is calculated from a graph PageRank distribution. These are not interchangeable. The shared phase labels are vocabulary, not evidence of a shared running state machine.Axiom 的 KL 散度比较声明的 P、Q 分布；Reflective 的 Shannon 熵来自图谱 PageRank 分布，两者不能混成同一指标；即使相态标签相似，也不证明存在共享的运行状态机
