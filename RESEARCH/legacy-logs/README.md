# Historical runtime logs (non-canonical)

This directory preserves two formerly root-level cumulative runtime logs from earlier experiments and maintenance handoffs. They are historical input/output traces, not the current GPT Native R1–R5 Daily/Weekly/Monthly canonical research artifacts, not execution certificates, and not an Independent GPT audit ledger.

- `ingestion.log` — retained byte-for-byte from the root path at the relocation commit; includes mixed dated legacy and later trace entries, so do not attribute every line to the original Jules producer
- `semantic_drift_audit.log` — retained byte-for-byte from the root path at the relocation commit; dated drift checks, not a substitute for current source-pinned alignment reports

Use the original Git revision and dated RESEARCH records for provenance and actual execution status. Moving these files changes their present location only; it does not replay or reclassify any historical run.
