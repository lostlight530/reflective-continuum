### Storage and search | ?????

Nodes are keyed by `(node_id, version)`. Edges are keyed by `(source_id, target_id, relationship, version)`, and both endpoints must exist at the same version. Every connection enables and verifies SQLite foreign-key enforcement. Node content is synchronized to an external-content FTS5 index by insert, update, and delete triggers; node upserts use `ON CONFLICT DO UPDATE`, not `REPLACE`.

### Deltas and analysis | ?????

The library exposes three bounded comparisons:

- Structural delta: sorted added, removed, and content-modified node identifiers between two versions.
- Search-result delta: whether the top lexical result changes for the same caller-declared query.
- Rank delta: nodes whose absolute PageRank score shift exceeds a caller-declared non-negative threshold.

PageRank input and configuration are validated, duplicate edges are collapsed, and output is normalized. Shannon entropy is calculated from normalized finite, non-negative PageRank scores and reported in nats. A threshold comparison is only a result for the declared graph, configuration, and revision; it does not establish intelligence, instability, truth, or safety.

### Validation, transactions, and hooks | ????????

`RuleConfig` is executable policy. Content and identifiers are validated explicitly; Python source checks use the AST and the current interpreter's standard-library module set. ADR prose is documentation and is never parsed for runtime constants.

`CortexObserver.process_input` validates caller data and performs accepted ingestion in one savepoint-backed transaction. Policy rejection returns a structured `ProcessResult`; unexpected database and programming errors propagate. If the configured entropy threshold is exceeded, an optional reflection hook runs at most once per configured depth and state is recomputed. Exhausting the configured bound rolls back the transaction.

Back up the database, record the schema and environment, migrate a copy, verify foreign keys and `PRAGMA integrity_check`, and test restore procedures before replacing an operational file.
