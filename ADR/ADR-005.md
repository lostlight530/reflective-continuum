# Entropy is a graph statistic, not cognition

- Decision date: 2026-08-05
- Scope: reflective-continuum storage, analysis, validation, tasks, and verification

## Status

Accepted.

- Supersedes named ADR: `NONE`
- Historical correction scope: replaces earlier prose that promoted PageRank-derived entropy or phase labels into cognition/safety/convergence claims; no predecessor file is asserted

## Context

Shannon entropy over PageRank can describe concentration but does not prove phase, safety, reflection quality, or convergence.

## Decision

Validate and normalize PageRank scores; report entropy in nats; treat threshold as caller policy with scope and calibration. Phase names are labels.

## Consequences

Metaphoric presentation remains possible but normative claims stay mathematical and bounded.

## Verification

Tests cover normalization, unknown endpoints, non-finite scores, and boundary configuration. Passing supports only the tested revision/configuration.

## Exceptions

An exception requires owner, expiry, affected failure/threat model, compensating control, test, migration when relevant, and rollback in a reviewed pull request.
