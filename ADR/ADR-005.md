# PageRank-derived Shannon entropy is a graph statistic

- Decision date: 2026-08-05
- Review calibration: 2026-08-24
- Status: Accepted
- Implementation anchor: `CODE/entropy_analyzer.py`

## Status

Accepted for the bounded reference implementation; broader system claims remain out of scope.

## Context

The repository computes Shannon entropy over normalized non-negative scores, commonly the PageRank distribution produced from one declared graph version.

The `LIQUID` / `GASEOUS` phase labels used by `CortexObserver` are local control labels around a configured threshold.

## Decision

`compute_pagerank()`:

- requires unique node IDs
- rejects invalid damping/iteration/tolerance configuration
- rejects edges referencing unknown nodes
- collapses duplicate edges
- normalizes the resulting rank distribution

`calculate_topological_entropy(scores)`:

- requires finite non-negative scores
- normalizes by total mass
- reports Shannon entropy in nats
- returns `0.0` for zero total mass

`check_phase_boundary(pagerank, threshold)` returns only whether graph-derived entropy exceeds the supplied non-negative threshold.

## Consequences

Callers receive an inspectable local contract but remain responsible for deployment, authority, persistence, and claims outside the named implementation surface.

## Verification

Verification requires a named repository path, revision, fixture or store identity, command, environment, exit code, and retained failures. Documentary review alone is not runtime or semantic validation.

## Evidence boundary

The resulting scalar describes the supplied rank distribution only.

It does not independently measure:

- semantic meaning
- truth
- cognition
- safety
- alignment
- persistence
- global convergence

A threshold crossing is a local policy condition under `RuleConfig`, not evidence of a physical or cognitive phase transition.
