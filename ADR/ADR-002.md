# Bounded reflection is a real loop

- Decision date: 2026-08-05
- Scope: reflective-continuum storage, analysis, validation, tasks, and verification

## Status

Accepted. Supersedes absolute or unverifiable language in the prior file.

## Context

The prior depth counter advanced only once per call and could report reflection without repeated observation.

## Decision

A boundary invokes an optional reflector and recomputes state for each depth 1..N. Persistent boundary exhausts N and rolls back. N is explicit RuleConfig.

## Consequences

No-op reflection can reject high-entropy input; callers must provide a tested transformation if desired.

## Verification

Observer tests assert exact depth, rollback, and propagated DB errors. Passing supports only the tested revision/configuration.

## Exceptions

An exception requires owner, expiry, affected failure/threat model, compensating control, test, migration when relevant, and rollback in a reviewed pull request.
