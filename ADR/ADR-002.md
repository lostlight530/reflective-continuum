# Bounded reflection is a transactional observer loop

- Decision date: 2026-08-05
- Review calibration: 2026-08-24
- Status: Accepted
- Implementation anchors: `CODE/cortex_observer.py`, `CODE/continuum_db.py`, `CODE/reflective_validator.py`

## Status

Accepted for the bounded reference implementation; broader system claims remain out of scope.

## Context

`CortexObserver.process_input()` implements a bounded local loop around one version-scoped graph update. “Reflection” is a project label for an optional caller-supplied hook followed by revalidation and metric recomputation.

## Decision

For one input:

1. validate node/content
2. open one `GraphDB` savepoint
3. insert the node and requested edges for the declared version
4. validate the resulting snapshot
5. compute PageRank and graph-derived entropy
6. if the configured boundary is not exceeded, return accepted
7. otherwise invoke the optional reflector once per depth from `1..max_depth`
8. revalidate and recompute after each reflector call
9. accept if the boundary clears
10. reject and roll back when validation fails or reflection depth is exhausted

Unexpected database/programming exceptions propagate after savepoint rollback.

## Consequences

Callers receive an inspectable local contract but remain responsible for deployment, authority, persistence, and claims outside the named implementation surface.

## Verification

Verification requires a named repository path, revision, fixture or store identity, command, environment, exit code, and retained failures. Documentary review alone is not runtime or semantic validation.

## Evidence boundary

`ProcessResult.accepted` means only that this local validation/transaction path accepted the input under the current rules and store identity.

It does not prove:

- semantic truth of content
- quality of the reflector
- durable persistence beyond the store used
- safety or alignment
- global convergence

A no-op reflector may therefore exhaust the bounded loop and cause rollback; that is expected reference behavior, not evidence of cognitive failure.
