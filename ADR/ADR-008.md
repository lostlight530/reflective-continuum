# Tasks do not own research records

- Decision date: 2026-08-05
- Scope: reflective-continuum storage, analysis, validation, tasks, and verification

## Status

Accepted.

- Supersedes named ADR: `NONE`
- Historical correction scope: replaces earlier task behavior that implicitly wrote research records or scanned undeclared repository state; no predecessor file is asserted

## Context

Tasks wrote dated files under RESEARCH, read ad-hoc root logs, recursively scanned unrelated files, and mixed scheduled intent with daily side effects.

## Decision

Tasks default to JSON stdout, inspect only declared DB/query/version inputs, and write only an explicit output path. RESEARCH remains separately owned. Schedulers choose cadence externally.

## Consequences

No automatic daily reports; operators must select storage, retention, and notification.

## Verification

Task tests verify observed values and absence of implicit output. Passing supports only the tested revision/configuration.

## Exceptions

An exception requires owner, expiry, affected failure/threat model, compensating control, test, migration when relevant, and rollback in a reviewed pull request.
