# Standard-library runtime and explicit contracts

- Decision date: 2026-08-05
- Scope: reflective-continuum storage, analysis, validation, tasks, and verification

## Status

Accepted. Supersedes absolute or unverifiable language in the prior file.

## Context

A small auditable core is valuable, but “zero dependency” cannot establish correctness or security.

## Decision

Runtime code uses Python standard library only; formats and errors are specified and tested on 3.12/3.14. ADR prose is never executable configuration.

## Consequences

Low supply-chain surface; callers still own SQLite build features and deployment controls.

## Verification

CI compile/tests, FTS5 selfcheck, AST import validation. Passing supports only the tested revision/configuration.

## Exceptions

An exception requires owner, expiry, affected failure/threat model, compensating control, test, migration when relevant, and rollback in a reviewed pull request.
