# Standard-library runtime with explicit local contracts

- Decision date: 2026-08-05
- Review calibration: 2026-08-24
- Status: Accepted
- Implementation anchors: `CODE/continuum_db.py`, `CODE/reflective_validator.py`, `CODE/entropy_analyzer.py`, `CODE/drift_detector.py`, `CODE/cortex_observer.py`

## Status

Accepted for the bounded reference implementation; broader system claims remain out of scope.

## Context

Reflective Continuum is a small standard-library Python reference. Dependency minimalism is an implementation property, not evidence of correctness, persistence, safety, or semantic validity.

## Decision

Describe behavior only through concrete executable contracts:

- SQLite graph storage and FTS5 behavior → `GraphDB`
- validation limits/import-root checks → `RuleConfig` / `RuleEngine`
- PageRank and Shannon-entropy calculations → `entropy_analyzer.py`
- version-scoped structural/lexical/rank comparisons → `drift_detector.py`
- transactional observation/reflection loop → `CortexObserver`

ADR prose is explanatory only and is never parsed into runtime constants.

Python-version compatibility is revision/environment-specific and is not inferred from documentation alone.

## Consequences

Callers receive an inspectable local contract but remain responsible for deployment, authority, persistence, and claims outside the named implementation surface.

## Verification

Verification requires a named repository path, revision, fixture or store identity, command, environment, exit code, and retained failures. Documentary review alone is not runtime or semantic validation.

## Evidence boundary

A successful local observation supports only the property actually observed for the opened store/input/revision.

Examples:

- foreign-key state applies to the opened SQLite connection
- stdlib-only import-root checking is not a sandbox
- snapshot digest identifies the declared graph snapshot, not durable continuity
- task-local selfcheck does not prove historical system health

## Non-goals

This ADR does not claim distributed storage, durable cross-task memory, authentication, authorization, sandboxing, semantic truth, autonomous alignment, or production-service readiness.
