# Structural, lexical top-result, and rank deltas are separate

- Decision date: 2026-08-05
- Review calibration: 2026-08-24
- Status: Accepted
- Implementation anchor: `CODE/drift_detector.py`

## Status

Accepted for the bounded reference implementation; broader system claims remain out of scope.

## Context

Reflective Continuum implements three different version comparisons. Their names must not be collapsed into one “semantic drift” or “alignment” score.

## Decision

### Structural delta

`compute_structural_delta(conn, v1, v2)` reports sorted node IDs that were added, removed, or whose stored content changed between the declared versions.

### Lexical top-result delta

The historically named `compute_semantic_delta()` runs a quoted FTS5 lexical query and returns whether the identity of the **top lexical result** differs between two versions.

Current semantic interpretation:

`LEXICAL_TOP_RESULT_CHANGED`

It is not embedding similarity, semantic-equivalence analysis, or general meaning change.

### Rank delta

`compute_rank_delta(pr1, pr2, threshold)` reports nodes whose absolute PageRank-score shift exceeds the supplied non-negative threshold.

## Consequences

Callers receive an inspectable local contract but remain responsible for deployment, authority, persistence, and claims outside the named implementation surface.

## Verification

Verification requires a named repository path, revision, fixture or store identity, command, environment, exit code, and retained failures. Documentary review alone is not runtime or semantic validation.

## Evidence boundary

Every drift claim names:

- compared versions
- query for lexical comparison
- threshold for rank comparison
- data/store identity where relevant
- which delta surface produced the result

An unchanged lexical top result does not prove unchanged meaning. A structural change does not prove semantic harm. A rank shift does not prove correctness or instability.

`verify_self_consistency()` delegates to the generic `RuleEngine`; it is not a dedicated drift-schema proof.
