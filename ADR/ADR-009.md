# Evaluation and claim scope follows the exact evidence surface

- Decision date: 2026-08-05
- Review calibration: 2026-08-24
- Status: Accepted

## Context

Reflective Continuum exposes multiple evidence surfaces that answer different questions. Stable hashes, successful selfchecks, local ingestion acceptance, lexical drift results, graph entropy, and Weekly task summaries are not interchangeable.

## Decision

Keep these evidence classes separate:

- database initialization / SQLite integrity
- foreign-key and FTS5 accessibility
- transaction commit or rollback
- snapshot digest identity
- fixed-fixture repeatability
- structural graph delta
- lexical top-result delta
- PageRank score delta
- graph-derived Shannon entropy
- rule-engine acceptance
- source-to-claim support
- durable persistence continuity
- historical task execution state

Examples:

- `cortex_selfcheck.py` supports only its named checks for the database it opened
- `convergence_drill.py` supports only repeatability of its fixed local SQLite fixture
- `semantic_drift_audit.py` supports selected-version structural/lexical comparisons for caller queries
- `InsightMorpher` acceptance supports only local ingestion/control-flow outcome
- a snapshot digest supports snapshot identity, not persistence through an unobserved interval

## Historical aggregation rule

A higher-level R3/R4/R5 artifact does not erase Daily R1/R2 failures, errors, rejected signals, missing runtime evidence, or `NOT_COMPUTED` dimensions.

Current evidence therefore preserves:

- 2026-08-07 through 2026-08-10 R2 `26 passed / 1 error`
- 2026-08-17 through 2026-08-23 R2 `26 passed / 1 failed`
- 2026-08-06 original R2 runtime as `HISTORICAL_RUNTIME_UNKNOWN`

## Evidence boundary

A successful observation supports the exact checked property and scope only.

It does not automatically establish semantic truth, alignment, safety, durable memory, global stability, or convergence.
