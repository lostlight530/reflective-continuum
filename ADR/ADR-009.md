# Evaluation and claim scope

- Decision date: 2026-08-05
- Scope: reflective-continuum storage, analysis, validation, tasks, and verification

## Status

Accepted. Supersedes absolute or unverifiable language in the prior file.

## Context

Repeatable hashes and passing selfchecks were described as deterministic convergence or alignment.

## Decision

Every result records revision/environment/fixture/query/budget and limitations. Repeatability, integrity, security, semantic validity, and agent behavior are separate claims. External AI evaluations include harness and budget.

## Consequences

Claims are less dramatic but reproducible and falsifiable.

## Verification

CI matrix, evidence baseline, reproducibility record, and protected-path compare. Passing supports only the tested revision/configuration.

## Exceptions

An exception requires owner, expiry, affected failure/threat model, compensating control, test, migration when relevant, and rollback in a reviewed pull request.
