# Transactional versioned graph schema

- Decision date: 2026-08-05
- Scope: reflective-continuum storage, analysis, validation, tasks, and verification

## Status

Accepted. Supersedes absolute or unverifiable language in the prior file.

## Context

Edges did not identify endpoint versions, foreign keys were off, replace-upsert conflicted with FTS triggers, and savepoint handling was injectable/incomplete.

## Decision

Enable/verify foreign keys; key nodes and edges by version; composite endpoint FKs; use ON CONFLICT UPDATE; validate/quote savepoints; rollback then release.

## Consequences

Existing DBs need migration; invalid edges fail immediately; FTS stays synchronized through explicit triggers.

## Verification

Database tests cover FK enforcement, two edge versions, upsert/search, injection rejection, and reusable rollback. Passing supports only the tested revision/configuration.

## Exceptions

An exception requires owner, expiry, affected failure/threat model, compensating control, test, migration when relevant, and rollback in a reviewed pull request.
