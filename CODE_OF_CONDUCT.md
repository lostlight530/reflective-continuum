# Code of Conduct

Contributors must be respectful, criticize artifacts rather than people, disclose uncertainty, and protect private or security-sensitive information. Harassment, discrimination, threats, doxxing, deliberate deception, and repeated disruption are unacceptable.

Technical disagreement is welcome. Observations, primary-source support, proposals, hypotheses, and contested claims must remain distinguishable. Reproducible counterexamples can overturn project language regardless of author or status.

Report conduct concerns privately through the repository owner’s GitHub profile contact route. Maintainers should minimize personal-data collection, avoid conflicts of interest, and respond proportionately through clarification, warning, restriction, or removal. Vulnerabilities belong in the private process in `SECURITY.md`.

This applies to issues, pull requests, discussions, reviews, and project-representative interactions.
